JARVIS — Guía de instalación y uso para analistas

LAFISE · Motor de búsqueda de soluciones Jira (SLGMS) · Puerto 8000

1. ¿Qué es JARVIS?

JARVIS indexa tickets cerrados de SLGMS y permite encontrar causa raíz, solución, SQL y casos similares en segundos.

2. Requisitos

RequisitoDetalle
NavegadorChrome, Edge o Firefox
Node.js 18+Solo si instalás JARVIS localmente
GitRecomendado para actualizar

3. Instalación

Solo usar (servidor del equipo)

Abrí la URL del equipo, ej. http://servidor:8000.

En tu PC (Windows)

  1. Clonar el repo JARVIS
  2. Doble clic en start.bat o ejecutar npm install y npm start
  3. Abrir http://localhost:8000

Sync Jira (admin)

Copiar .env.example → .env con JIRA_EMAIL, JIRA_API_TOKEN, JIRA_PROJECT=SLGMS.

4. Uso diario

Búsqueda

Tokens AND: sistema + error + reporte. Ejemplos: SISNET ORA-00942, SLGMS-2076.

Atajos: / buscar · Esc limpiar.

Filtros

Sistema, Área usuaria, Analista — escribí para autocompletar.

Orden

  • Más reciente — últimos cierres
  • Relevancia — mejor solución documentada
  • Filtro fecha y Solo solución útil

Tarjeta

Link Jira, causa/solución copiables, SQL, casos similares, badge solución débil.

5. Tips JIRA — 4 datos mínimos

#PreguntaEjemplo
1¿Qué falló?[SISNET - Emisión] ORA-00001 al guardar póliza
2¿Por qué?Secuencia desfasada en polizas_master
3¿Cómo se arregló?Ajuste de secuencia + script SQL
4¿Cómo se validó?Emisión OK con test_qa en PRE/PRO

SQL en JARVIS: usar bloques ```sql en Solución y re-sincronizar.

6. Calidad y ranking

Botón Calidad: score = 50% solución + 30% causa + 20% SQL (mín. 5 casos por analista).

7. Sincronizar Jira

Web → Sincronizar Jira o node scripts\sync-jira-api.js. Primera sync ~1 año; luego incremental.

8. Problemas frecuentes

SíntomaSolución
No abreVerificar servidor; cambiar puerto
Sin notasSync Jira
Ticket no apareceDebe estar Cerrado en SLGMS

9. Flujo del analista

Incidente → Buscar JARVIS → Casos similares → Resolver → Cerrar Jira (Tips JIRA) → Sync
