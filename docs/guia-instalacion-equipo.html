JARVIS — Guía de instalación para el equipo

LAFISE · SLGMS · Versión 1.5.0 · Puerto 8000

1. Requisitos

  • Node.js 18+ (nodejs.org)
  • Token API Atlassian (Jira Cloud)
  • Windows 10/11 recomendado

2. Instalación

  1. Descomprimir jarvis-1.5.0-*.zip en C:\JARVIS (o similar).
  2. copy .env.example .env y completar email + token Jira.
  3. Primera sync: npm install y node scripts\sync-jira-api.js --full.
  4. Backfill CSAT (una vez): npm run sync:satisfaction:backfill.
  5. Arrancar: doble clic en start.bat.
  6. Navegador: http://localhost:8000

3. Configuración .env

JIRA_BASE_URL=https://seguroslafise.atlassian.net
JIRA_EMAIL=tu.correo@lafise.com
JIRA_API_TOKEN=tu_token
JIRA_PROJECT=SLGMS
JIRA_SYNC_ON_START=1
JIRA_SATISFACTION_SYNC=1

# Opcional — solo SISNET/OPTICO (purga notas fuera del filtro)
# JIRA_SYNC_SISTEMA_FILTER=SISNET,OPTICO

Token: id.atlassian.com → API tokens

6. Servidor compartido

Instalar en servidor, --full + backfill CSAT una vez, dejar start.bat corriendo. URL: http://servidor:8000. Analistas solo navegador.
