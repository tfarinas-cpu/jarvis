JARVIS — Guía de instalación para el equipo

LAFISE · SLGMS · Puerto 8000

1. Requisitos

  • Node.js 18+ (nodejs.org)
  • Token API Atlassian (Jira Cloud)
  • Windows 10/11 recomendado

2. Instalación

  1. Descomprimir el ZIP en C:\JARVIS (o similar).
  2. copy .env.example .env y completar email + token Jira.
  3. Primera sync: npm install y node scripts\sync-jira-api.js --full.
  4. Arrancar: doble clic en start.bat.
  5. Navegador: http://localhost:8000

3. Configuración .env

JIRA_BASE_URL=https://seguroslafise.atlassian.net
JIRA_EMAIL=tu.correo@lafise.com
JIRA_API_TOKEN=tu_token
JIRA_PROJECT=SLGMS
JIRA_SYNC_ON_START=1

Token: id.atlassian.com → API tokens

4. Uso diario

AcciónComando / acción
Arrancarstart.bat
Sync nuevos casosBotón Sincronizar en la web
DetenerCtrl+C en la consola

5. Servidor compartido

Instalar en un servidor, sync --full una vez, dejar start.bat corriendo y compartir http://servidor:8000. Los analistas solo necesitan navegador.
