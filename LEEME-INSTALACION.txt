================================================================================
  JARVIS 1.5.0 - Motor de busqueda de soluciones HD (Jira SLGMS)
  Guia rapida de instalacion - Windows
================================================================================

REQUISITOS
  - Node.js 18+  https://nodejs.org/
  - Token API Atlassian (Jira Cloud)

PASOS
  1. Descomprimir el ZIP en una carpeta (ej. C:\JARVIS)

  2. Configurar Jira:
       copy .env.example .env
     Editar .env con tu correo y JIRA_API_TOKEN
     Token: https://id.atlassian.com/manage-profile/security/api-tokens

  3. Primera sync (historico):
       npm install
       node scripts\sync-jira-api.js --full

  4. Backfill CSAT (una vez, recomendado):
       npm run sync:satisfaction:backfill

  5. Arrancar:
       Doble clic en start.bat
       Navegador: http://localhost:8000

USO DIARIO
  - start.bat para levantar el servicio
  - Boton "Sincronizar Jira" trae solo casos nuevos/actualizados
  - Boton "Insights" = top incidencias recurrentes + propuestas de mejora
  - Boton "Tema" = modo claro/oscuro (no forzar dark en Chrome)
  - Filtros: Sistema, Area, Analista, Solicitante
  - Ctrl+C en la consola para detener

GUIA COMPLETA
  docs\guia-instalacion-equipo.md
  docs\guia-instalacion-equipo.html  (imprimir / PDF)
  docs\guia-analistas-jarvis.md      (uso del buscador)

PROBLEMAS FRECUENTES
  - Pocos casos: repetir sync --full
  - Sync falla: revisar .env (email + token)
  - Sin CSAT historico: npm run sync:satisfaction:backfill
  - Puerto ocupado: taskkill o cambiar PORT en .env
